Training

How it trained

3,000 steps of AdamW, batches of 32 × 64 characters, on a laptop CPU. Each point averages 50 batches with dropout switched off.

Generation

What it writes

Real output from the trained checkpoint. It learned the shape of my profile cards (a header, a category, bullet lists) and fills them with recombined fragments. “VIELP, APPLICIQ” is invented: after “PROJECT CARD: ” the letter V had a 2.4% chance at temperature 0.7, and the sampler picked it.

8 samples of 300 characters per temperature. Lower temperature, more memorization: with 826,465 parameters and about 100K unique characters of text, copying is easier than generalizing.

Debugging

What broke, and what I learned

Some of these crashed far from their cause. Others ran without complaint and quietly gave wrong results. Each one taught me more about PyTorch than reading did.

Lesson 1The split scrambled my text

Symptom
The training text decoded to 'eeoIrsvpiNeP rtlt=u =nJpp wt 0"ou Huod'.
Cause
random_split shuffles items, and every item was a single character.
Fix
Two slices: data[:n] and data[n:].

Shuffle which windows you pick, never the characters inside them.

Lesson 2One block instead of four

Symptom
231,649 parameters instead of 826,465. Shapes and loss looked normal.
Cause
self.block = Block() built a single block.
Fix
nn.Sequential(*[Block() for _ in range(n_layer)])

The gap was exactly 3 × 198,272. Only the parameter count could see it.

Lesson 3& is not %

Symptom
Evaluations at steps 0, 1, 4, 5, 256, 257… 49 of them instead of 13. The chart above comes from that run.
Cause
step & 250 is a bitwise AND. I meant step % 250.
Fix
One character.

The bugs that run without errors are the expensive ones.

Lesson 4The learning rate never arrived

Symptom
None. Training just ran.
Cause
lr = 3e-3 was defined but never passed, so AdamW used its default of 1e-3.
Fix
torch.optim.AdamW(model.parameters(), lr=lr)

An argument you forget to pass becomes a silent default.

Lesson 5Slicing the wrong axis

Symptom
IndexError: index out of range inside the position embedding, 52 characters into generation.
Cause
idx[-64:] slices rows of a (1, T) tensor, so nothing was cropped. At T = 65 the position table ran out.
Fix
idx[:, -64:]

In a 2-D slice, the comma separates rows from columns.

Lesson 6The validation set was inside the training set

Symptom
Validation loss kept falling to 0.59 and never pulled away from training loss.
Cause
The corpus repeats itself: 5,030 lines, only 2,173 unique. Every 64-character window of the validation text also appears in the training text.
Fix
For the next version: remove duplicates first, then split.

A validation set only means something if the model has never seen it.
